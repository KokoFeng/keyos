# KeyOS - keyboard ala iOS untuk Android (Feng iOS on Droid)

Isi: zona sentuh adaptif (cara kerja keyboard iPhone), popup tombol ala iOS, tekan-lama aksen,
trackpad spasi, emoji iOS, 8 tema, saran kata + kalkulator, mikrofon, suara ketik.

Aset yang kamu taruh sendiri (dari folder Download):
  app/src/main/res/raw/standard.ogg, spacebar.ogg, delete.ogg, ret.ogg
  app/src/main/assets/fonts/ios_emoji.ttf   (font emoji iOS)
Daftar kata lebih lengkap: ganti app/src/main/assets/words_en.txt / words_id.txt
(satu kata per baris, urut dari yang paling sering dipakai).
